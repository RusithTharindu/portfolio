# Bento Portfolio

Personal portfolio of **Rusith Tharindu Thushan** — software engineer building resilient full-stack systems.

**[rusiththarindu.github.io/bento-portfolio](https://rusiththarindu.github.io/portfolio)**

---

Built with Next.js 16, React 19, Tailwind CSS v4, and Motion. Ships as a fully static site on GitHub Pages.

## Running locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### GitHub Activity (optional)

The activity section pulls live contribution data from the GitHub GraphQL API. Create `.env.local`:

```bash
GH_USERNAME=your-github-username
GH_TOKEN=your-read-only-github-token
```

Without these, the section falls back to sample data — the site still builds and runs fine.
